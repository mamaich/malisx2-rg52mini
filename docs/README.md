# Документация форка malisx2 для RG52 Mini

Что сделано, что планируется и почему — для тех, кто продолжает работу над
драйвером. Общее описание форка — в [../README.md](../README.md).

| файл | о чём |
|---|---|
| [building.md](building.md) | сборка: что нужно, отладочная сборка, как в образе (LTO + PGO), снятие профиля PGO, проверка своей сборки на устройстве |
| [changes.md](changes.md) | что сделано по сравнению с апстримом, по коммитам, и что из этого проверено на устройстве |
| [plans.md](plans.md) | что планируется и в каком порядке |
| [decisions.md](decisions.md) | принятые решения, а также что отложено и что отброшено, с причинами |
| [hardware.md](hardware.md) | особенности Mali-G52, RK3562 и драйвера ядра kbase, найденные по ходу работы |
| [emulators.md](emulators.md) | что делают эмуляторы (Dolphin, ARMSX2, Azahar) и что из этого следует для драйвера |
| [debugging.md](debugging.md) | как ловить падения и мерить: переменные окружения, захват заданий, поиск упавшего задания |
| [darkos.md](darkos.md) | как malisx2 встроен в dArkOS: выбор драйвера, сборка в образе, PGO, выпуск |

Даты в документах — по времени работы над форком; цифры скорости — с
устройства, с указанием, кто и как мерил.
